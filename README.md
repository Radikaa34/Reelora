# 🎬 Reelora

**Your personal entertainment discovery space.**

Reelora is an animated entertainment website designed for people who love movies, anime, books, dramas, and web series. It brings different entertainment interests together in one place with a modern interface, engaging visuals, and smooth animations.

## ✨ Features

- 🎥 **Entertainment Discovery** — Explore movies, anime, books, dramas, and web series.
- 🔥 **Trending Section** — Discover trending entertainment content.
- 🎨 **Modern UI** — Enjoy a clean, visually appealing interface.
- ✨ **Animations** — Experience smooth transitions and interactive visual elements.
- 📱 **Responsive Design** — Designed to provide a comfortable browsing experience across screen sizes.

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** CSS
- **Development Tools:** Node.js, npm

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your system.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/reelora.git
   ```

2. Navigate to the project directory:

   ```bash
   cd reelora
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
